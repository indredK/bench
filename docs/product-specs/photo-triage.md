# Photo Triage（照片筛选）产品说明

> 本文件是 photo-triage 模块的**完备产品规格**。一切功能改动、优化、bug 修复都必须同步更新本文件。
> 自包含、可移植：复制到任何项目或交给任何 AI，可据此完整复刻本模块功能。

## 1. 定位

- **独立旁路模块**（macOS-only，非 Bench 主序列），入口：路由 `/photo-triage`，侧边栏注册，仅 macOS 显示。

- 用途：在爱思助手等导出的相册目录中快速「留 / 删」筛选。

- 核心保证：图/视频同名配对（Live Photo 识别为 `live`）；删除一律进系统废纸篓可恢复；可批量移动到任意目标文件夹；稳定 ID 与 manifest 结构与 Python 原版逐字节一致，已有标记不丢失。

### 欢迎页

- 「选择照片目录…」：tauri-plugin-dialog 原生选目录，用户主动选择即视为授权（无 TCC 弹窗）。

- 后台扫描：事件推进度（读取目录 / 生成预览），可取消；最近 8 个相册可「继续上次进度」直接续接。

- 无 ffmpeg 时提示（视频降级为静态封面）。

## 3. 缩略图条（左栏）

### 宽度拖拽与多列自适应（Splitter）

- **右侧分隔条**（缩略图条与预览区之间）：鼠标按住**左右拖动**调整缩略图栏宽度（范围 220px \~ 窗口 80%），**双击恢复默认 320px**。

- 宽度随 localStorage 记忆（`photo-triage:stripW`），下次进入自动恢复。

- **多列自适应**：列数 = `floor((面板宽 + 8) / (96 + 8))`，即每列最小 96px，面板越宽列数越多——**拖宽分隔条即可显示更多缩略图列**，一屏看到更多照片；卡片为正方形（宽=高），不被压缩变形。

### 虚拟滚动

- 按行虚拟化（`@tanstack/react-virtual`，overscan 4）：只渲染视口附近的行，几千条也秒开、滚动流畅。

- 行 = 分组头行（sticky 吸顶）+ 网格行（每行 cols 张缩略图）。

### 缩略图卡片

- 正方形卡片，圆角，黑底；按需生成代理图（见 §8），加载中显示**文件名占位**，加载失败也显示文件名。

- 状态角标：

  - `实况` badge（Live Photo）；`▶` badge（视频）

  - 边框色：激活（当前项）= 主色；留 = 绿；删 = 红

  - 选中 = 主色边框 + ✓ 角标（左下）

  - 已删 = 整卡淡化（opacity .35）+ 右下角「已删」红标

- 卡片可多选、可拖拽（见 §6、§7）。

### 分组头

- 分组开启时，每组前显示吸顶分组头「📁 名称」，根目录显示「（根目录）」，虚线分隔。

## 4. 分组索引条（最左缘水平刻度）★

> 即「水平标记 / 水平刻度」：分组开启时显示在缩略图区最左缘的一列竖向排列的**水平小刻度**，用于快速跳转与展示每组加载进度。

- **显示条件**：分组开启（G）且当前可见条目 **> 24**（条目太少没有跳转价值）。

- **刻度布局**：每个分组一个刻度，`flex:1` 均分整列高度（min-height 6px），分组再多也全部可见。

- **刻度外观**：水平小圆条，常态 9×2px、弱化灰色；`hover` 或**当前分组**时变蓝并加宽到 13×3px。

- **加载进度填充**：每条刻度按该组「已加载缩略图数 / 总数」从**两端向中心**渐变填充（CSS `--p` 0..1）——橙色 = 加载中，**填满变绿色**；未开始加载（0/N）为空心。

- **hover 提示（tooltip）**：悬停立即弹出文件夹名；该组未加载完时额外显示「已加载/总数」（**含 0/N**），且随缩略图加载**实时刷新**；tooltip 用 portal 渲染到 body、fixed 定位贴索引条右侧并钳制在视口内，**不被容器裁剪**（原生 title 延迟太久，故自绘）。

- **当前分组高亮**：视口顶部所在分组的刻度**常亮蓝色**，随滚动实时同步（rAF 合并，只在跨组变化时更新）。

- **点击跳转**：点击刻度 → 缩略图条滚动到该分组顶部（就近加载该区域缩略图）。

## 5. 预览区（右侧）

- **大图**：按需生成代理（最长边 1600，HEIC→JPEG），等比 contain 填满预览区。

- **视频**：4 秒预览片段（ffmpeg），无 ffmpeg 时静态封面（qlmanage 兜底）；原生控件播放，空格播放/暂停。

- **Live Photo**：`L` 切换静态 ⇄ 动态（有视频片段时）。

- **Lightbox 大图查看**：点击大图进入全屏：`fit → 100% → 200%` 循环缩放（点图切换），方便判断清晰度；`Esc` / 点击空白关闭。

- **meta 栏**：文件名（`~` 缩写路径）、类型标签（图片/视频/实况）、大小（MB）、序号（N/总数）、实况切换、← 上一张 / 留 / 删 / 恢复 / 下一张 →。

- 大图可**拖拽到文件夹卡片**移动（见 §7）。

## 6. 多选

- `⌘/Ctrl+点击` 切换选中；`Shift+点击` 从上次点击处**范围选**；`Esc` 清空。

- `⌘A` 或「全选」按钮：全选当前筛选下全部条目（排除已删）。

- **全选 toggle**：已全选时再点同一按钮 / 再按 `⌘A` **取消全选**；按钮文案「全选 ↔ 取消全选」。

- 选中项显示 ✓ 角标；待选栏显示「已选 N 项」。

- 移动目标优先级：多选 > 当前项。

## 7. 拖拽移动（缩略图 / 大图 → 待选文件夹卡片）★

- **拖拽源**：缩略图卡片、预览大图均可拖；多选包含当前项时拖动整组。

- **鼠标跟随图**：`dataTransfer.setDragImage` 克隆源元素（WKWebView 对普通 div 默认不生成 ghost），限宽高、半透明、居中。

- **拖拽中界面反馈（拖虚化）**：

  - **无关区域虚化**：header / 工具栏 / 底部 meta / 分隔条统一淡化至 `opacity .35`，突出待选栏落点。用 `opacity` 而非 `blur`——WebKit 对拖拽源祖先改渲染上下文会取消拖拽，且对几百张缩略图逐帧 blur 是卡顿主因。**拖拽源所在的缩略图区 / 预览区保持原样，不虚化**。

  - 待选栏内描边高亮 + 泛蓝提示可放置；所有文件夹卡片边框泛蓝。

  - chip 子元素 `pointer-events:none`：悬停命中始终落在卡片本身，避免 dragover/dragleave 抖动。

  - 页面根节点 `dragover/drop preventDefault`：防止 WKWebView 把拖拽文本当 URL 导航跳空白页。

- **拖到待选栏上下边缘 26px 自动滚动**：文件夹多也能拖到被挡住的卡片。

- **放置二次确认**：拖放后弹确认框「将 N 项移入 📁 xxx？」确认才移动；**点击卡片直接移动**（不确认）。

- **移动后**：toast「已把 N 项移入 📁 xxx」；留/删标记随 id 迁移；已删状态同步迁移；移出相册目录的条目从列表移除（保留滚动位置）；多选清空；目标卡片 +N 计数并持久化。

- 右键卡片：在访达中显示该文件夹。

## 8. 缩略图加载调度（防疯狂加载）★

- **按需生成**：`ensure_proxy` 生成一次永久缓存（写 `.part` 后原子改名），重复浏览零重复生成。

- **并发闸门**：前端固定 **8 并发**（`THUMB_CONC=8`）队列调度——完成一个取下一个，即使一次挂载几十张也同时只跑 8 个。

- **到限度即停**：只加载「当前挂载」的缩略图（视口 + 少量预渲染），**加载完即停**；滚动到新行才继续排队加载。点击跳到照片多的分组不会疯狂加载。

- 后端另有 `Semaphore`（图 6 / 视频 2）双保险；预览大图/视频走直连不排队（即时加载）。

## 9. 标记 / 筛选 / 分组（工具栏与键盘）

### 标记

- `K` 标记留、`D` 标记删（**同键再按一次取消**）；`U` 撤销上一步（撤销栈 300 条）。

- 标记后自动跳（autoNext，默认开）：跳下一个未处理项。

### 筛选（`F` 循环）

- 全部 / 未处理 / 留 / 删 / 已删（pill 按钮带计数）。

- 语义：`deleted` 只显示已删；`todo` 未处理；`keep`/`drop` 对应标记；`all` 全部。

- `0` 跳下一个未处理项。

### 分组（`G` 开关）

- 按 `folder` 聚合，同组保持原始相对顺序；分组头「📁 名称」。

- 工具栏分组按钮：关闭显示「分组：关」，**开启显示「分组：N 组」**（N=分组数）。

## 10. 操作闭环

- **顶部统计**：共 / 留 / 删 / 未处理 / 已删 实时计数。

- **全部标记留/删**：二次确认后批量覆盖标记（重置撤销栈）。

- **移入废纸篓**：批量二次确认（显示条目数 / 文件数 / 文件路径列表）；仅某条目全部文件都移入成功才标记已删，失败项保留可重试；删除一律进系统废纸篓可恢复。

- **从废纸篓恢复**（后悔药）：`R` 或按钮；恢复成功自动标记「留」。

- **重置缓存**：核对清单——废纸篓已清空的已删条目、原文件丢失的条目，直接从列表移除。

- **清理空文件夹**：找出相册目录下完全为空的目录（含隐藏文件如 .DS\_Store 就不算空）；勾选 + **二次确认**删除，只删空目录本身。

- **导出**：导出 selection.json（`{source, keeps[], drops[]}`）浏览器下载。

- 相册路径显示：`/Users/<name>/...` 缩写为 `~`（hover 显示完整路径）。

## 12. 技术实现要点

- **架构**：前端 `src/features/photo-triage/`（React + zustand + @tanstack/react-virtual）；后端 `src-tauri/src/photo_triage/`（scan / preview / trash\_ops / export / commands / state / types）。

- **稳定 ID**：`md5(相对路径去扩展名)[:12]`，与 Python 版逐字节一致；后缀大小写不敏感。

- **扫描配对**：按「相对路径去扩展名」分组图/视频；同 key 有图有视频 → `live`，仅图 → `photo`，仅视频 → `video`。

- **数据目录**：`$APPDATA/photo-triage/build-<md5(src)[:10]>`，每相册独立构建目录，跨会话增量复用；manifest 原子写（.tmp + rename）；上限 256MB（约 40 万条目）。

- **预览通道**：asset 协议 `convertFileSrc` 加载，零序列化开销；源目录运行时放通。

- **拖拽**：`tauri.conf.json` 窗口级 `dragDropEnabled: false`（放行页内 HTML5 拖拽）；`setDragImage` 克隆源元素作跟随图。

- **持久化**：localStorage 按相册记忆——`photo-triage:state:<src>`（sel/deletedIds/groupBy/autoNext/filter/folderCandidates/movedCounts）、`photo-triage:folders:<src>`、`photo-triage:moved:<src>`、`photo-triage:stripW`（缩略图栏宽度）。

- **i18n**：zh/en 双语；占位符用双花括号 `{{var}}`（i18next 标准）。

- **平台**：Rust `#[cfg(target_os = "macos")]` 编译门控，非 macOS 返回 `unsupported`；`Info.plist` 含 TCC usage description。

## 13. 数据模型

`PhotoItem`：`id` / `type`(`live|photo|video`) / `stem` / `folder`(`.`=根目录，移出相册后为绝对路径) / `image` / `video` / `image_proxy` / `video_proxy` / `video_poster` / `size_bytes` / `deleted` / `trash`。

store 关键状态：`sel`(id→keep|drop)、`deletedIds`、`filter`、`groupBy`、`autoNext`、`liveView`、`currentId`、`multiSel`、`folderCandidates`、`movedCounts`、`loadedIds`(缩略图加载完成集)、`proxy`(id:kind→路径缓存)、`stripWidth`、`dragActive`、`currentFolder`。

## 14. 异常处理

| 场景                  | 行为 / 提示                                                                                                                    | 恢复 / 降级                                                  |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------ |
| 扫描失败 / 用户取消   | 前端 `loadError` 展示错误（`SCAN_CANCELED` 原样返回不写清单），回欢迎页可重试                                                  | 事件监听 finally 清理，防重入（`scanning` 门控）             |
| 打开历史目录 TCC 拒绝 | 结构化错误 → `loadError` 展示，**不静默失败**                                                                                  | 提示后可回欢迎页重新选目录                                   |
| 预览代理生成失败      | `ensureProxy` 返回 null → 缩略图占位显示文件名，**不阻塞滚动**；成功/失败都计入 `loadedIds`（刻度不卡半格）                    | 失败项可重试（再次进入视口重新请求）                         |
| 大量缩略图加载失败    | 缩略图显示文件名占位                                                                                                           | （py 有「旧标签页缓存」10 次失败提示；React 版未实现该提示） |
| 移动失败              | 无目标条目 → toast「没有可移动的条目」；已在废纸篓 → toast「已在废纸篓的条目不能移动」；后端部分失败 → toast warn + 控制台错误 | 失败项保留原位，可重试；成功项正常更新                       |
| 移入废纸篓部分失败    | toast「已移入 N 个；M 个出错（详见控制台）」                                                                                   | 仅当某条目**全部文件**都移入成功才标记已删，失败项保留可重试 |
| 从废纸篓恢复部分失败  | toast「已恢复 N 个；M 个出错」                                                                                                 | 恢复成功项自动标记「留」                                     |
| 重置缓存              | 核对失效条目（废纸篓已清空 / 文件丢失），toast「移除 N 个，保留 M 个」，有移除则刷新                                           | 失败 toast「请求失败」                                       |
| 清理空文件夹          | 无空目录 → 空态「没有找到空文件夹」；部分删除失败 → toast warn + 控制台                                                        | 删除后重扫（父目录可能也空了）                               |
| 预览命令失败          | 大图区显示「无法生成预览（原文件可能损坏或格式未支持）」                                                                       | 打开系统播放器兜底                                           |
| 后端 IPC 异常         | `getErrorMessage` 归一化 → toast / `loadError` 展示                                                                            | 命令层返回 `AppResult` 结构化错误                            |
| 无 ffmpeg             | 视频静态封面 + 提示「未安装 ffmpeg」                                                                                           | 播放降级系统播放器                                           |

**并发与幂等**：扫描后台事件推进度、可取消；缩略图前端 8 并发闸门 + Rust Semaphore 双保险；移动/废纸篓/恢复按「全部文件成功才标记状态」保证幂等；重复浏览代理缓存命中零重复生成。

## 15. 边界与限制

- 仅 macOS（sips/qlmanage 系统自带）；Windows 隐藏入口。

- 无 ffmpeg：视频仅静态封面，播放降级为系统播放器。

- 删除一律走系统废纸篓，禁止直接 `remove_file`；批量删除 / 批量移动 / 清理空文件夹均强制二次确认。

- 超大相册靠虚拟滚动 + 按需代理，扫描进度可取消。

- 与 Python 版行为漂移风险点：稳定 ID 与 manifest 结构保持一致（可交叉比对）。
