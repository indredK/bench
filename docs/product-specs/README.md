# 产品功能规格（Product Specs）

> 本目录是各模块**产品功能规格的唯一真相源**（Reference 层）。自包含、可移植：复制到其他项目或交给任何 AI，可据此完整复刻模块功能。

## 结构

每模块一个文件：`<模块名>.md`，与 `src/features/<模块名>/` 一一对应（16 个模块全覆盖）。

## 统一模板（每份文档均含）

1. **定位** — 入口、平台、sidecar/desktopOnly、用途、核心保证
2. **界面与功能** — 布局示意 + 逐区块功能清单（每控件交互）
3. **快捷键**（如有）
4. **交互细节** — 空态/失败态/加载态/禁用态、hover/右键/双击、防重入、二次确认、键盘、状态流转
5. **异常处理** — 错误码→提示映射、失败场景→降级/重试、幂等/取消/并发
6. **技术实现要点** — 架构分层、IPC、持久化、边界（简单分点）
7. **数据模型** — 关键类型/状态
8. **边界与限制** — 平台差异、安全/合规红线

## 维护规则

- **任何功能改动 / 优化 / bug 修复都必须同步本文件**（先在 `../planned/<模块名>.md` 变更记录追加一行）。
- 实现完成的规划项：从 `../planned/<模块名>.md` 移除，并更新本文件对应小节。
- 新增 feature：按模板新建 `<模块名>.md`，同时建 `../planned/<模块名>.md` 与 `../modules/<模块名>/`。
- 与 `docs/modules/<模块名>/README.md` 的关系：modules README 只保留定位一句话 + 文档索引，功能细节一律在本目录。
