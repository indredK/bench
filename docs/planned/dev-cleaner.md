# Dev Cleaner（开发者清理）规划功能

> 本文件记录 dev-cleaner 模块**未实现 / 待验证**的功能规划，与 `../product-specs/dev-cleaner.md` 同结构。
> 实现一项即从本文件移除，并同步到产品说明；规划新增功能先写到这里再开发。

## 说明（模块归属）

Dev Cleaner 是 Clean Space 的内部扫描/清理引擎，**不独立规划产品功能**。扫描进度、自定义目录、清理记录和跨平台适配统一在 [Clean Space roadmap](../modules/clean-space/roadmap.md) 跟踪，避免双份 backlog 漂移（来源：`docs/modules/dev-cleaner/roadmap.md`）。

## 待验证（真机）

- [ ] macOS 真机：项目扫描（含 pnpm 硬链接 store、Mixed 多语言工程、深层 node_modules）的尺寸统计与去重在真实工程上无误报、无卡顿。
- [ ] 删除进废纸篓后可在原位置恢复（osascript Finder delete）；权限拒绝/受保护目录返回结构化错误。
- [ ] 自定义清理各内置命令在干净环境下的成功/失败/超时语义与释放量估算准确性。
- [ ] Windows 废纸篓（SendToRecycleBin）与 PowerShell 尺寸统计（`-LiteralPath`、CREATE_NO_WINDOW）真机验证。

## 待实现（代码缺口）

- 暂无（当前实现闭环：扫描 → 筛选/选择 → 确认 → 清理 → 自动重扫；自定义清理命令库内置）。

## 远期

- [ ] **自定义清理命令可配置化**：目前 12 个命令为后端硬编码内置；若需支持用户自定义命令，必须先建立「白名单 + 参数校验 + 风险分级」机制，禁止直接放行任意 shell 字符串。
- [ ] **扫描与清理性能**：超大目录树（数千项目）的扫描进度事件与取消响应优化（当前为整树一次性返回结果）。
