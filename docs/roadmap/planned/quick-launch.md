# Quick Launch（快速启动）规划功能

> 本文件记录 quick-launch 模块**未实现 / 待验证**的功能规划，与 `../product-specs/quick-launch.md` 同结构。
> 实现一项即从本文件移除，并同步到产品说明；规划新增功能先写到这里再开发。

## 待验证（真机，来源：roadmap + 全局 R02）

### 按需扫描与快照恢复（D-019）

- [ ] 真机验证：应用启动进入 quick-launch 不触发全量扫描；首次使用（无缓存）展示空状态 + 扫描按钮，点击后才扫描。
- [ ] 真机验证：扫描完成一次后重启应用，进入 quick-launch 显示上次快照（含「恢复上次的应用列表」骨架过渡），手动重新扫描后图标与数据刷新，且新快照回写磁盘缓存。

### 发布前必须完成

- [ ] Windows EXE/AUMID 与 macOS `.app` 真机启动 smoke（`appId -> LaunchTarget`）。
- [ ] 500+ 应用虚拟列表性能和 DOM 数量验收（当前为「>48 项页面滚动普通网格」方案）。

## 待实现（代码缺口）

- [ ] **大列表虚拟化**：页面当前用普通 CSS 网格渲染大场景（>48 项），design.md 约束「大列表使用 `VirtualGridView`」尚未落实；500/2000 项 fixture 验收通过前不应宣称性能达标。
- [ ] **未使用类型清理**：`LaunchAppEntry`（`pinned` 字段）未被消费，待确认外部消费者后清理（roadmap 远期）。

## 远期

- [ ] **分类命中解释**：向用户展示「为何归入此场景」及 `platform/source/exact ID` 优先级治理（roadmap 远期）。
- [ ] **使用频率 / 最近使用 / 固定项**：需先定义隐私与留存策略（roadmap 远期）。
