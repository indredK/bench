# Network Probe（网络探测 / 网络急救箱）规划功能

> 本文件记录 network-probe 模块**未实现 / 待验证**的功能规划，与 `../product-specs/network-probe.md` 同结构。
> 实现一项即从本文件移除，并同步到产品说明；规划新增功能先写到这里再开发。
> 来源：`../modules/network-probe/roadmap.md` 的 Wave 表格（⬜ 待实现 / ◐ 部分完成）、ROADMAP 与 design 文档。

## 当前状态

- 模块 1.0 / MVP A+B 已闭环（D-016）。
- Post-MVP：测速 + Globalping DNS/ping/HTTP 与可选 token + 自有 agent HTTPS 客户端 + 安全/发现主路径已交付；服务 / OS 指纹已完成 macOS 实机验收；特权 helper、自有 agent 服务端兼容验收仍待。

### Wave 3 · 安全 Tab（续）

- [ ] **S3-8** 特权分层：`priv-helper` / 触发提权 / 自动降级文案（依赖 Wave 1）。

### Post-MVP-Adv · 发现默认资源

- [x] **D3-1** 将 STUN/NTP 服务器名单接入 Defaults Catalog 与用户覆盖/重置；发现页提供编辑、保存、分组恢复；局部保存保留其他目录类别，并以原子写入、进程互斥和 OS 文件锁协调并发实例。

### Wave 5 · Polish 增强（产品化）

- [x] **P5-2** 固定站点持续监控 / 阈值告警：官方站点与所选站点包可立即探测并按 30/60/300 秒间隔串行重复；HTTP TTFB 优先、ICMP 回退，失败或达到用户阈值在面板提示；停止及离开面板停止后续轮次。
- [x] **P5-3** 健康报告历史快照 + 跨时间对比：可选择两份快照比较检查状态与建议增减；历史本机可关闭，关闭或清空均确认，兼容无采集时间的旧记录。
- [x] **P5-4** 一体化 BasicView 视觉合并：主页汇总本机网络、最近体检状态/计数与优先建议；体检运行/取消和「上不了网」入口位于顶部；保留原 L2 深度面板，不伪造健康分数。

### Wave 2 · Post-MVP-C（续）

- [ ] **C2-3** 自有 agent 远程执行端到端闭环（部分完成）：
  - [x] HTTPS HMAC-SHA256 客户端、Keychain token、健康检查、DNS/ping/HTTP 白名单执行请求、429 映射、目标护栏、`nodeId` 结果隔离。
  - [ ] 接入兼容的 agent 服务端，真机验证健康状态、三种真实测量、HMAC 过期 / nonce 重放拒绝、QPS / 并发限制、429 重试时间和服务端 DNS rebinding / SSRF 护栏。Bench 当前不附带服务端；没有真实 endpoint 验收前不勾选 C2-3 完成。
  - [ ] Globalping 与自建 agent 的通用并排对比视图。
  - WSS 不在本期客户端协议范围；Windows agent UI / TLS / Keychain 回归待用户安排 Windows 环境。

## 待验证（真机 / 行为）

- [ ] macOS 真机：Local Network / TCC 权限不足时各探测（ping/ARP/抓包）的稳定错误码与「打开系统设置」引导生效。
- [ ] macOS 真机：直连网络下 traceroute 特权 ICMP 失败后，确认无特权 UDP 可产生有效跳点。本次 QA 真机通过 `utun4` 路由探测 `1.1.1.1`，两种方式最终均不可用；UI 已显示本地化失败恢复提示，没有验证到成功跳点。
- [ ] 测速源不可用 / 超时 → 30s 冷却倒计时在真机可用；取消测速可立即重跑。
- [ ] `priv-helper` 提权路径（Wave 1 pack）在真实系统上可安装、触发提权、自动降级文案正确。
- [ ] 能力包 hash 校验失败通道（`installCapabilityPackVerifyFail`）行为符合预期。
- [ ] Windows 降级路径：各工具 `unsupported`/`degraded` 状态与按钮禁用一致，不误报。代码审查发现 traceroute 能力矩阵目前把 Windows 标成 `supported`，但 Windows 执行路径仅尝试特权 ICMP、无提权或无特权回退；标准用户界面可能误启用。用户安排本轮目标完成后再提供 Windows 环境回归；在此之前不宣称已修复或验证。

## 远期（Vision P5–P7 · Wave 6）

> 体积与合规风险最高，需单独授权范围。

- [ ] **V6-1** 网络配置向导（静态 IP / 路由 / VPN / 防火墙 · 三次确认）。
- [ ] **V6-2** 重型抓包（会话重组 / 应用层解码 · 按需加载 · 强依赖 pack）。
- [ ] **V6-3** 邮件诊断：SPF/DKIM/DMARC、RBL、邮件服务器。
- [ ] **V6-4** SNMP / BGP / VLAN 企业网管。
- [ ] **V6-5** 按进程流量监控（nethogs 类，可独立子模块）。
- [ ] **V6-6** 授权资产审计（nuclei/amass 风格 · **仅授权资产** · 强授权 UX）。

## 红线（不实现）

- 主动攻击能力：ARP 欺骗攻击 / MITM 流量注入 / DoS / 密码爆破 → 违法，绝不构建（每波验收含 S-X-06 红线负向）。
